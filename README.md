# AI 여행 상담소

초등학교 5학년 실과 「생활과 수송」 활동 2를 위한 반응형 수업 웹앱입니다. 실제 생성형 AI API 없이 규칙 기반 추천과 샘플 데이터만으로 작동합니다.

## 주요 기능

- 모둠별 5개 여행 상황 선택
- 상황별 규칙 기반 AI 추천 예시
- 시간·비용·안전·환경·편리성 별점 평가
- AI 추천에서 발견한 점과 수정안 작성
- 입력 내용이 자동 반영되는 최종 발표 카드
- 활동 진행률 및 완료 조건 표시
- 태블릿과 휴대전화에 대응하는 반응형 화면

## 실행 방법

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 열어 확인합니다.

완성본 빌드:

```bash
npm run build
```

## Vercel 배포

저장소를 Vercel에서 가져오면 `vercel.json`에 따라 Next.js 프로젝트로 자동 인식됩니다.
빌드 명령은 `npx next build`, 설치 명령은 `npm ci`로 설정되어 있습니다.

## Netlify 배포

`netlify.toml`에 Next.js 빌드 명령과 게시 위치가 설정되어 있습니다.
Netlify에서 프로젝트 폴더나 압축 파일을 가져오면 `npx next build`를 실행하고
`.next` 결과물을 게시합니다.

## 파일 구조

```text
.
├─ app/
│  ├─ page.tsx       # 여행 상황 데이터와 전체 활동 화면
│  ├─ layout.tsx     # 한국어 문서 및 공유 메타데이터
│  └─ globals.css    # Tailwind CSS와 반응형 디자인
├─ public/
│  └─ og.png         # 링크 공유용 미리보기 이미지
├─ .openai/
│  └─ hosting.json   # 사이트 게시 설정
├─ package.json
└─ README.md
```

## 수업 활용 흐름

1. 모둠 상황을 선택합니다.
2. AI 추천 예시를 읽고 이동 수단과 근거를 확인합니다.
3. 다섯 가지 관점으로 평가하고 빠뜨린 점을 기록합니다.
4. 더 알맞은 이동 계획으로 수정합니다.
5. 자동 완성된 카드로 최종 계획을 발표합니다.

> 추천 내용은 수업용 예시입니다. 실제 이동에 사용할 때는 최신 시간표, 비용, 날씨, 안전 정보를 반드시 확인해야 합니다.
